# 木の条件を探ろう

グラフを操作して木の性質を発見する、依存ライブラリ不要の学習用Webアプリです。

## 起動

リポジトリのルートで `python3 -m http.server 4173 --directory tree-lab/dist` を実行し、http://localhost:4173 を開きます。

## 検証

`node tree-lab/tests/graph.test.mjs`

4・5頂点の全1,088グラフを独立した単純道探索による判定と照合し、4〜10頂点の問題を840例検証します。

## 判定

- 無向単純グラフ。道は頂点を繰り返さない単純道です。
- 条件5は各辺を削除した後の非連結性を調べます。初めから非連結なら○、辺がない場合も全称命題として○です。
- 条件6は存在しない各辺を追加したグラフに閉路があるかを判定します。既存の閉路も含みます。完全グラフは追加可能な辺がないため「—」です。
- 木は連結かつ閉路なしで判定。6つの性質の文章は常に表示します。判定表示OFFでは結果を「？」にし、ONでは判定結果と木のメッセージを表示します。
- 問題タイプは4種を循環。第4タイプは辺数n−1の非連結なグラフです。

## 操作

頂点を2つ選ぶと辺を追加、辺を選ぶと削除、ドラッグで頂点を移動します。Tabで移動、Enter/Spaceで選択、Escで選択解除できます。リセットは自由モードでは辺なし、問題モードでは問題開始時に戻ります。

## ファイル

- `tree-lab/dist/index.html`: 画面
- `tree-lab/dist/style.css`: レスポンシブデザイン
- `tree-lab/dist/app.mjs`: 操作・表示
- `tree-lab/dist/graph.mjs`: 数学的判定・問題生成
- `tree-lab/tests/graph.test.mjs`: 独立した検証
